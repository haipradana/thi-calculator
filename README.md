# BMKG Temperature Humidity Index Calculator

Web kalkulator sederhana sebagai tugas magang project 2 di Stasiun Klimatologi DI Yogyakarta. Web ini menerapkan dua jenis perhitungan berdasarkan rumus yang ditetapkan oleh NOAA (Amerika Serikat) dan THI Tropis dengan persamaan Nieuwolt.

Live Demo: [bmkg-thi.pradanayahya.com](https://bmkg-thi.pradanayahya.com)

# Apa itu THI?

Suhu yang tertera pada termometer tidak selalu sama dengan apa yang dirasakan oleh tubuh manusia. Kelembapan udara memainkan peran penting dalam sensasi panas yang dirasakan tersebut. Aplikasi web ini menggunakan dua pendekatan:

1. Heat Index (NWS/NOAA): Indeks panas yang menggabungkan suhu udara dan kelembapan relatif untuk menentukan "suhu yang dirasakan" (apparent temperature). Standar ini sering digunakan untuk peringatan bahaya kesehatan (heat stroke).
2. THI Tropis (Nieuwolt): Temperature Humidity Index dengan rumus yang dikhususkan untuk wilayah beriklim tropis seperti Indonesia, mengklasifikasikan kenyamanan dari "Nyaman" hingga "Sangat Tidak Nyaman".
